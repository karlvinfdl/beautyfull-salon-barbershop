# 💈 BeautyFull Salon & Barbershop

Site vitrine premium + système de prise de rendez-vous en ligne pour le salon **BeautyFull Salon & Barbershop** basé à **Évry-Courcouronnes (91000)**.

Développé en **HTML / CSS / JavaScript natif** avec **Vite**, et hébergé sur **GitHub Pages**, ce projet permet aux clients de réserver un créneau, et aux administrateurs de gérer les réservations via un panneau dédié.

---

## 🚀 Fonctionnalités

### 🖥️ Côté client
- ✔️ Page d’accueil premium (thème **noir / rouge / or**)
- ✔️ Menu responsive fullscreen
- ✔️ Galerie photos + vidéos avec défilement automatique
- ✔️ Présentation des services (Homme / Femme / Enfant)
- ✔️ Avis clients dynamiques
- ✔️ Formulaire de **prise de rendez-vous**
  - Sélection de la **date** et de l’**heure**
  - Créneaux automatiquement **bloqués** lorsqu’ils sont déjà réservés
  - Enregistrement **local** + **cloud Firebase**
  - Envoi automatique d’un message WhatsApp de confirmation au salon

---

### 🔐 Côté administrateur
- ✔️ Accès sécurisé par code secret :
- ✔️ Panneau de gestion des rendez-vous
- ✔️ Deux sources de données distinctes :
  - **LocalStorage** (rendez-vous pris sur l’appareil actuel)
  - **Cloud Firestore** (rendez-vous en ligne partagés)
- ✔️ Suppression individuelle ou totale des rendez-vous locaux
- ✔️ Suppression d’un rendez-vous cloud en un clic
- ✔️ Interface **responsive** convertissant le tableau en **cartes lisibles** sur mobile
